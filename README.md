# Glowithsya

Glowithsya adalah aplikasi web sederhana untuk membantu proses
booking layanan Makeup Artist.

Project ini dikembangkan pada mata kuliah Konstruksi dan
Evolusi Perangkat Lunak.

## Fitur yang Direncanakan

### Customer
- Melihat informasi Glowithsya
- Melihat layanan makeup
- Melakukan booking
- Memilih tanggal dan jadwal yang tersedia
- Melihat informasi pembayaran QRIS
- Melakukan konfirmasi melalui WhatsApp

### Admin
- Login
- Melihat data booking
- Mengubah status booking
- Mengelola layanan

## Teknologi

- Laravel
- PHP
- Blade
- CSS
- JavaScript
- MySQL
- GitHub Actions
